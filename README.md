# Vórtex+ 🌪️

O **Vórtex+** é um sistema inteligente criado para facilitar e automatizar a captação de potenciais clientes (leads) na internet e direcioná-los de forma organizada para grupos de WhatsApp.

Se você está fazendo um lançamento, um evento online, ou apenas quer captar contatos interessados no seu produto, o Vórtex+ é o motor por trás disso.

## 🎯 Qual é o objetivo do sistema?

O objetivo principal do Vórtex+ é **não perder nenhuma oportunidade de venda ou contato**. Ele funciona como um funil perfeito:

1. **A Página de Captura (Landing Page)**
   O sistema permite que você crie formulários personalizados dentro das suas próprias páginas na internet. Quando um visitante (potencial cliente) entra na sua página, ele preenche os dados dele (como Nome, E-mail, Telefone, Idade, etc).
   
2. **O Banco de Dados (Cofre de Leads)**
   Assim que a pessoa clica em "Quero Participar", o Vórtex+ salva todas as informações desse contato de forma segura. Isso cria a sua lista de clientes (sua base de leads), que você pode consultar, analisar e usar para vendas no futuro.

3. **O Rotacionador (A Mágica do WhatsApp)**
   Depois que a pessoa deixa os dados, ela é automaticamente redirecionada para um Grupo de WhatsApp do seu evento. O grande diferencial do Vórtex+ é que ele **rotaciona** esses grupos. Se o "Grupo 01" encher (ex: bater 200 pessoas), o sistema percebe isso sozinho e começa a mandar as próximas pessoas automaticamente para o "Grupo 02", e assim por diante. 

## 🛠️ O que você (como administrador) pode fazer?

Através de um Painel de Controle simples e intuitivo, você consegue:

- **Criar Campanhas:** Cada evento ou produto que você for lançar pode ter uma campanha própria.
- **Montar Formulários:** Escolher exatamente quais perguntas você quer fazer para o seu público.
- **Gerenciar Grupos:** Cadastrar os links dos seus grupos de WhatsApp e definir quantas pessoas cabem em cada um.
- **Acompanhar Resultados:** Ver quantas pessoas se cadastraram no total e como estão enchendo os seus grupos.

Tudo isso sem precisar entender de programação, códigos complexos ou integrações difíceis. O Vórtex+ cuida da tecnologia para que você foque nas suas vendas!
